# Simulador Fila Banheiro
## Descrição do Problema
Simula a fila para o único banheiro de um laboratório de engenharia com base na taxa de chegada e tempo de uso.
## Requisitos
- Calcular o tempo médio de espera dos usuários.
- Gerar o número total de usuários atendidos em 1 hora.
## Exemplo de Uso
Chegadas: 12, Tempo médio uso: 5min
Saída: Total usuários: 12, Tempo médio espera: 25.0 min
